# 审计问题分批修复与验证（2026-10-15）

本轮接续用户“逐步修复问题”的指令，保留既有未提交改动，不提交 Git。第一批覆盖四项问题及一项性能优化；未把后续队列或平台发布验收记为已完成。

## 第一批实现

| 问题                                         | 修复与验证边界                                                                                                                                                                                                                                                 |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `workspace.apply` 绕过正常写入审批与会话策略 | RPC 复用 `workspaceResultTools`、`ToolRegistry` 与 `createRunApprover`，在执行前重新检查当前会话文件策略及权限策略；审批绑定结果 ID、摘要和文件预览。真实临时仓库覆盖拒绝、只读、审批期间撤销权限、人工批准及预览期间新增冲突。                                |
| 隔离子代理误用执行目录校验历史所属项目       | 历史工具按逻辑项目作用域装配，文件工具仍使用执行目录。真实 Agent 回归覆盖自己的读取、搜索、跟踪，父会话读取，项目搜索及跨项目拒绝。                                                                                                                            |
| `run.cancel` 无法取消手动压缩                | 用带会话身份的 `manualOperation` 管理压缩和 RPC 导入，取消仅中止所属会话操作，关闭 Host 也会中止。HTTP 夹具覆盖取消压缩后未提交摘要、能再次压缩；导入回归覆盖取消审批后未改文件、未记文件变更、释放占用并能再次导入。配置读取也纳入压缩的 `finally` 释放范围。 |
| 受保护安装包发布清单错误选择普通安装包       | 发布脚本显式选择 `standard/protected` 配置与当前支持的 `x64` 架构；受保护打包命令传入对应参数。夹具覆盖仅受保护包、同时存在旧普通包以及缺失受保护包时拒绝回退。未执行安装、签名或生产发布。                                                                    |
| 重试计数查询扫描所有会话事件                 | `run-request.ts` 向已有的 `retryCount` 接口传递 `sessionId`，使查询可使用会话索引。未声称实际耗时收益。                                                                                                                                                        |

独立审查发现并补齐了一个相关集成问题：`workspace.apply` 加入 `HOST_LONG_REQUESTS`，避免普通 RPC 截止时间先于人工审批到期。真实 stdio Host 与客户端回归将普通截止时间设为 1 秒，在收到审批后额外等待 1.1 秒，确认没有提前写入，随后批准并验证实际导入。临时移除长请求分类时，测试明确因 `REQUEST_TIMEOUT`、`outcomeUnknown` 失败；恢复分类后通过。

RPC 的冲突响应保持结构化，审批及其他真实错误继续拒绝请求。桌面当前未接入 `workspace.apply` 的专用交互入口，本轮验证范围是 Host、AgentHostClient 与现有原始审批事件，不能据此声称桌面导入 UI 已验收。
