# 审计问题逐项修复（2026-10-07）

按现有审计顺序处理 Web URL 异常、浏览器重复事件、WebSocket 资源上限与接收成本、分片状态校验，以及桌面后台浮层的不稳定性。每项先用真实行为回归复现，再最小修改、定向验证和独立审查；最后重新执行完整门禁。真实模型与安装包不属于本次验证范围。

## 1. Web URL 异常

静态资源 URL 的解析与百分号解码现在纳入异常捕获，非法请求返回 400。HTTP 异步回调增加拒绝处理，避免异常成为未处理 Promise 拒绝。升级入口的 URL 解析也返回 400 并结束连接；认证及文件路径约束沿用现有逻辑。

新增真实 HTTP 请求验证 `/%ZZ`、`/%`、`/%E0%A4%A`，原实现以 `URIError`／未处理拒绝失败；新增原始 TCP 升级请求 `GET //%ZZ HTTP/1.1`，原实现以 `ERR_INVALID_URL`／未捕获异常失败。两种异常请求被拒绝后，均验证 `/health` 正常。另核对目录遍历仍返回 403、缺失资源仍返回 404。

定向验证：`npm run smoke:web` 4/4，`npm run typecheck` 与修改文件格式检查通过。独立审查补充发现升级入口的同根异常，已按上述失败回归修复并复核。完整门禁在全部修复结束后重新执行，不以此前审计的全量结果代替本次验证。

## 2. 浏览器并发连接与重复事件

连接建立期间复用同一个 Promise，每个 WebSocket 只安装一次事件监听器。连接关闭时拒绝未完成连接和请求；正在关闭的旧连接被新连接替换之前，先结算其请求，旧连接后续事件不再污染新连接。

新增直接调用 `createBrowserBridge` 的真实 Host 回归，先复现 `single chunksingle chunk`，修改后只收到 `single chunk`。真实 WebSocket 服务另验证断线请求结算、并发重连，以及旧关闭握手尚未结束时的新请求；最后一项由独立审查发现，先以“旧请求未结算”失败，再补充修复。

定向验证：浏览器桥 3/3、Web 冒烟 4/4；类型检查通过。新增测试文件已同步 README 生成事实。首次失败回归暴露测试自身清理顺序不正确，已改为先关闭 Host 再删除临时工作区，并清理那次遗留测试进程。

## 3. WebSocket 接收资源与重复拷贝

帧与累计文本消息默认上限均为 64,000,000 字节，与 Host JSONL 传输默认值一致。超大帧在长度头解析后、等待载荷前拒绝，真实连接返回 1009；累计分片在完整帧交给组装器时检查。帧接收与分片组装均使用封顶的倍增缓冲，完整大帧及消息完成后释放缓冲。

先复现超大帧未被拒绝、累计分片超限，以及 2 MiB 分块输入造成约 540 MB 拷贝。独立审查另发现小分片对象放大：500,001 个 1 字节分片在 GC 后仍保留约 57 MB 堆内存。新增真实解码器与组装器的子进程内存回归先失败，改成连续缓冲后通过；同时验证完整文本内容。测试使用宽松内存预算，不以耗时作为门槛。

定向验证：帧测试 13/13、Web 冒烟 5/5、类型检查通过。独立复核另验证 64 MB 正常大帧、11 种 TCP 分块大小及零／恰好上限／超限预算，无新增阻塞问题。

## 4. WebSocket 分片状态与编码边界

未完成的分片消息中出现另一个文本消息时返回协议错误；UTF-8 在完整消息组装后校验，因此仍允许字符跨分片传输并保留 BOM。校验关闭状态码、关闭帧载荷和长度最短编码，关闭原因按完整 UTF-8 字符边界截断。协议依据为 [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455.html) 第 5、7、8 节。

五组新增回归在原实现均失败；修改后帧 18/18、实际浏览器桥 3/3，通过真实连接验证 1002／1007／1009 关闭码及服务存活。独立审查另复现同一包的 Close 后仍执行请求：真实 Host 的会话数从 1 增至 2。新增回归等待真实 dispatch 副作用完成并比较会话列表；修复接收入口关闭守卫与 Close 分支返回后，Web 冒烟 8/8。类型检查通过。

## 5. Windows 常规 CI 覆盖

常规 `push`／PR／手动 CI 的 Windows job 在构建前串行运行现有 Windows 沙箱、桌面安装路径与安装安全定向测试。本机运行 16/16，无跳过；独立审查确认测试无需构建、不启动安装器，安装安全验证仅调用校验函数。GitHub 托管 runner 尚未执行；若其受限 token 后端不可用，沙箱测试仍会按已有规则说明跳过原因。真实安装、升级和卸载保留在原 tag／手动安装工作流中。
