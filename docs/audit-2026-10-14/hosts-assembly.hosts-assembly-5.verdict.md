**Corrections:**

- Severity overstated: the finding's own "affected shape" (a client calling the method directly instead of the paged helper) excludes every shipped consumer. The desktop/CLI path, the retained Web bridge and the ACP SDK all use the paged `display` read; `packages/sdk/acp.ts` is paused anyway. The unpaged form is exercised only by tests and the benchmark harness. That makes this a latent protocol-surface gap, not a reachable-in-product failure — hence **low**, not medium.
- The trigger is narrower than the finding implies. `providerState` is opaque continuation state and is usually far smaller than the visible answer; the realistic accumulators are hydrated images (≈5 MB each, 4 per turn) or many-megabyte answers across many turns. Reaching >64 MB needs roughly a dozen-plus large image turns or a very long session, and the finding's "roughly eight large `providerState` turns" assumes 9 MB of _state_ per turn, which the cited test does not show — `tests/large-response.test.ts:181` repeats an answer text, and the assertion at `:237` exists precisely because `providerState` is not the big part.
- "the Host builds that multi-megabyte string in memory first" is correct but ordinary for any reply; the 64 MB `lineFramer` cap is deliberate, tested behaviour (`tests/host-carrier.test.ts:224-235`), not an accidental cliff.

**Reasoning:** Every line cited lands where the finding says, and the asymmetry with the deliberately bounded paged branch is genuine: one optional field decides whether a reply is bounded at 15 MB/page or unbounded, and the unbounded variant transports opaque continuation state the paged variant was designed to keep off the wire. But no shipped caller issues that call — the desktop, Web bridge and (paused) ACP SDK all read through the paged `display` path — and the reports' own framing ("a client that calls this method directly… is the affected shape") concedes it, so this is a real-but-low-impact protocol gap rather than a medium reliability defect. The recommended fix (bounded default, or an explicit refusal above the 15 MB page budget) is still sound and cheap.
