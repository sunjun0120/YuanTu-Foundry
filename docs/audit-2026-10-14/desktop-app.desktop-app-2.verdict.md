**Corrections:**

- Severity `medium` → `low`. The divergence is real but only visible (a) while an unsaved preview is active, (b) in native dialogs, or (c) behind the filename-prefixed attachment error path; it self-corrects on save, on restart, and for DOM text even on switching back.
- The headline impact list is largely moot: "settings validation errors … the model-settings busy refusal … a failed sandbox initialization" are exact dictionary values rendered into skippable-free DOM, so the walker displays them in the window's language (en) even though the main process composed them in zh. The auditor cited that very walker as the mechanism in the sibling finding and then ignored it here.
- The symptom that does exist runs mostly the _other_ way: persisted `en-US` + renderer previewing `zh-CN` shows main-composed English dictionary text (`Enter an API key.`, `Wait for the current operation to finish before …`) in a Chinese window, because `translatedText` early-returns for `zh-CN` (i18n.ts:1073) and cannot map en→zh.
- README:766 is not as flatly contradicted as claimed: for DOM text the shared dictionary really does keep the label and its error in the same visible language; the failing cases are native dialogs and filename-prefixed attachment errors, which that sentence does not cover.

**Reasoning:** The mechanism the finding describes is exactly as cited — the renderer switches language on `change`, the main process only on save, and nothing re-syncs the general form — so the two-process split is genuine and its line references are accurate. But the concrete failures it lists are healed by the i18n DOM walker, which translates those exact Chinese dictionary values (zh→en) into the settings and sandbox feedback elements, leaving only native dialogs (export/workspace `mainText` titles) and filename-prefixed attachment errors as observable mixed-language output. That residue is a transient, cosmetic inconsistency in an unsaved-preview state that the smoke test treats as deliberate, so it is a low-severity correctness wart rather than a medium one.
